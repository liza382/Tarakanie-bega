# Tarakanie-bega
Руководство пользователя
Данная игра "Тараканьи бега" является увлекательной и интересной игрой для всех возрастов!
Цель игры заключается в том , что бы тараканы пришли к финишую.
Интерфейс:

Для начала игры необходимо ввести имена двух игроков и нажать "Старт".После этого тараканы начинают двигаться по своим дорожкам. Побеждает тот участник, чей таракан первым достигнет финиша. Для начала нового раунда нажмите кнопку "Сброс", что бы вернуть тараканов на стартовые позиции.

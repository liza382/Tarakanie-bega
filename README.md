# Tarakanie-bega
Руководство пользователя
Данная игра "Тараканьи бега" является увлекательной и интересной игрой для всех возрастов!
Цель игры заключается в том , что бы тараканы пришли к финишую.
Интерфейс:
1. Для начала игры необходимо ввести имена двух игроков.
  <img width="802" height="483" alt="Рисунок2" src="https://github.com/user-attachments/assets/0b89b028-200e-4144-bf30-e36c991edca6" />
2.  нажать "Старт" после этого тараканы начинают двигаться по своим дорожкам
   <img width="798" height="485" alt="Рисунок3" src="https://github.com/user-attachments/assets/14023858-9239-4792-9f25-84b08e0dfc3a" />
3. Побеждает тот участник, чей таракан первым достигнет финиша
   <img width="802" height="478" alt="Рисунок4" src="https://github.com/user-attachments/assets/592b3d88-f9c6-488a-bef2-36076b8d6eff" />
4. Для начала нового раунда нажмите кнопку "Сброс", что бы вернуть тараканов на стартовые позиции.
   <img width="798" height="480" alt="Рисунок5" src="https://github.com/user-attachments/assets/448edcf2-72db-4ead-92eb-181864ffaf90" />
